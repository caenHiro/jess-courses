## Ejercicio 1 — Cronologia de un ataque real (obligatorio)

Investiga el ataque **WannaCry (2017)** y responde:

1. Que tipo de malware fue? (clasifica segun los tipos de la teoria)
2. Como se propagaba? No necesitaba interaccion del usuario?
3. Cual fue el error que permitio que se propagara tanto?
4. Que habria evitado el ataque si las organizaciones lo hubieran hecho?
5. Construye una cronologia: fecha, evento, impacto

**Fuentes:** Wikipedia, Kaspersky Blog, BBC News.

**Formato de entrega:** nota en `04_Notas_Personales/semana01_ej1.md`

## Ejercicio 2 — Mapa de actores y triada CIA (obligatorio)

Para cada escenario, identifica:
- Que principio de la CIA Triad se viola
- Que tipo de actor lo realizo
- Como se pudo prevenir

**Escenario A:** Un empleado descontento de una empresa copia la base de datos de clientes antes de renunciar y la vende en la dark web.

**Escenario B:** Hackers de un estado extranjero modifican los resultados de una base de datos electoral antes de publicarse.

**Escenario C:** Un grupo anonimo bombardea con trafico un sitio de noticias para que no pueda publicar durante elecciones.

**Escenario D:** Una empresa de ciberseguridad descubre una vulnerabilidad critica en el software bancario de 50 paises y la reporta responsablemente.

## Ejercicio 3 — Reto: "Have I Been Pwned" + analisis (reto)

**Parte A:**
1. Ve a `haveibeenpwned.com`
2. Ingresa tu email (o uno de prueba que uses)
3. Documenta cuantas brechas aparecen y en que servicios
4. Para cada brecha: que datos fueron expuestos?

**Parte B:**
Elige UNA de las brechas y responde:
- Que vulnerabilidad probable causo la brecha?
- Como pudo el atacante exfiltrar los datos?
- Que deberia haber hecho la empresa para prevenirlo?
- Si tu password estaba expuesto, que consecuencias tiene aunque ya lo cambiaras?

**Parte C:**
Revisa si usas la misma contrasena en multiples sitios. Si es asi, cambia todas. Documenta el proceso de gestion de contrasenas que usaras de ahora en adelante (password manager, reglas de creacion).
