# Curso 3 — Ciberseguridad (Jess)

Curso practico de 8 semanas orientado a Blue Team Junior / Analista SOC Nivel 1.

## Temas

| Semana | Tema |
|--------|------|
| 01 | Fundamentos: CIA Triad, actores, tipos de ataque |
| 02 | Redes: Wireshark, nmap, HTTP/HTTPS, DNS |
| 03 | Linux: permisos, procesos, logs, scripting |
| 04 | OWASP Top 10 en WebGoat |
| 05 | Ataques: SQLi avanzado, JWT, SSRF, Spring Boot |
| 06 | Criptografia: AES, RSA, bcrypt, JWT, OAuth |
| 07 | CTF: TryHackMe, PicoCTF, Burp Suite |
| 08 | Blue Team: Wazuh, respuesta a incidentes |

## Como empezar

```bash
git clone https://github.com/caenHiro/jess-security-course
cd jess-security-course

# Leer la guia
open vault/00_Guia_Uso.md

# Instalar herramientas
open vault/01_Instalacion/00_Stack_del_Curso.md
```

## Subir avances

```bash
bash scripts/push.sh "semana-01 completada"
```

## Prerequisitos

- Curso 1 Java completado
- Curso 2 Python+AWS completado
- Conocimiento basico de Python y APIs REST
